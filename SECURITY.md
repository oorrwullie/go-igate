# Reporting a security problem

If you find a vulnerability in Sparky, thank you for looking out for the people using it.

Please don't open a public issue containing exploit details, credentials, or information that could put someone's station at risk. Use [GitHub private vulnerability reporting](https://github.com/oorrwullie/sparky/security/advisories/new) if the repository has enabled it. If it is unavailable, use the repository maintainer's published private contact method, if available, or open a public issue asking for a private reporting channel **without describing the vulnerability**.

Include the affected version or commit, the relevant configuration (with secrets removed), the impact, and safe reproduction steps. Use local fixtures or systems you own or have permission to test. Do not access other people's stations or transmit unauthorized traffic.

There is no promised response deadline or formal supported-version schedule at present. We appreciate coordinated disclosure and will work to understand and address credible reports.

For ordinary bugs that do not expose a security issue, use the [issue templates](https://github.com/oorrwullie/sparky/issues/new/choose).
