# Welcome to the workbench

Radio is one of those hobbies where the more you learn, the more interesting things you find to learn about. That's a big part of the fun.

Sparky happens to be a piece of software, but the stuff it does is interesting even if you never install it. How does a little radio packet end up as a dot on a map? How can a computer listen to an airplane? Why can a tiny inexpensive USB receiver do so much?

Those are the sorts of questions we're going to explore here. You don't need to be a programmer, an electronics expert, or even a licensed ham to start learning.

## Start here

- [Getting your amateur radio license (US)](amateur-radio-license.md) — it's probably less intimidating than you think.
- [Understanding APRS](aprs.md) — little packets, big possibilities.
- [What an iGate actually does](igate.md) — getting packets from the airwaves onto the internet.
- [How digipeaters work](digipeaters.md) — helping radio packets travel a little farther.
- [Getting started with SDR](sdr.md) — turning a computer into a radio receiver.
- [Understanding ADS-B](adsb.md) — listening to aircraft position reports.
- [MQTT and radio data](mqtt.md) — how computers hand messages to one another.

Start with receive-only experiments. There is a surprising amount you can do without transmitting anything. When you're ready to transmit, make sure you're licensed and understand your local rules and operating practices.

For actual installation commands, go to the [Sparky documentation](../README.md). As new projects are built and tested, we'll add practical tutorials here rather than pretend that every future Sparky feature already exists.

Questions and corrections are welcome. Nobody knows everything about this hobby, and that's okay.
