# Be good to each other

Sparky is a place to learn, experiment and build things together. Whether you're sending your first pull request or have been working with radios for decades, you're welcome here.

We ask everyone to be curious, patient and respectful. Explain your reasoning, welcome questions, and critique ideas or code rather than people. Disagreement is fine. Harassment, discrimination, threats, unwanted sexual attention, publishing someone's private information and other abusive behavior are not.

These expectations apply to project issues, pull requests, documentation and other official project spaces.

If something happens, contact a maintainer privately using a published contact method if available. If none is available, ask for a private contact channel without posting sensitive details. Maintainers may remove harmful content, warn or restrict participants, or block accounts as appropriate. We will handle reports with discretion where possible; we cannot guarantee confidentiality on public platforms.

We don't need to agree on everything to learn from each other.
